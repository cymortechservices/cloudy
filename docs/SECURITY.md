# Security
Implemented: verified Supabase tokens; server-side ownership filters on every query (404 for both "missing" and "not yours"); strict Zod schemas (unknown fields rejected, blocking mass assignment such as `ownerId` or `quota_bytes`); server-generated object keys; extension+MIME allowlist and magic-byte check; size limit; atomic quota reservation; short-lived presigned URLs; Helmet, CORS allowlist, JSON body limit, per-user rate limits; no stack traces in responses; private bucket; PWA service worker never caches API or storage responses; text previews rendered as text, never HTML.

Not done / honest limits: no end-to-end encryption; no malware scanning; no independent audit; magic-byte checks cover only the first bytes (Office files are zip containers, so a renamed zip passes); signed R2 URLs cannot enforce content-length range beyond what is signed, so size is re-verified after upload; auth endpoints are rate limited by Supabase, not by this API; Privacy/Terms pages are drafts that need legal review.
